# Data

The original datasets are not redistributed in this repository.

The experiments use:

- UNSW-NB15
- NF-ToN-IoT-v3
- NF-UNSW-NB15-v3
- NF-CSE-CIC-IDS2018-v3 for independent external evaluation

The local experimental notebook expects data files under the project
data directory. Dataset acquisition and preprocessing details should
be documented in the accompanying paper and repository README.

`unsw_feature_docs.csv` is included because it is part of the
documentation input used by the constraint-extraction procedure.
